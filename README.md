# Hand Pilot

**Играть онлайн: https://motion-omega-nine.vercel.app** — открой в Chrome, разреши камеру, ничего устанавливать не нужно. Сразу к боссу: https://motion-omega-nine.vercel.app/?stage=3

Космическая аркада в браузере, которой управляешь двумя руками через обычную веб-камеру. Руки держат невидимый штурвал: наклон поворачивает корабль, кулаки стреляют, ладони рядом включают щит, поднятые пальцы запускают ракету. Миссия — прорваться через астероидное поле и лазерную засаду и уничтожить крейсер «Тиран». Если жест получился неточно, игра говорит, какой палец поправить.

**Направление:** A / Game · кейс «Motion», Admit Hackathon 2026.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Откройте адрес, который напишет Vite (обычно http://localhost:5173), и разрешите доступ к камере. Камера в браузере работает только на `localhost` или по HTTPS. Сядьте в 50–80 см от камеры: в кадре нужны только руки.

| Команда | Что делает |
| --- | --- |
| `npm run dev` | dev-сервер |
| `npm run build` | проверка типов и production-сборка в `dist/` |
| `npm run preview` | локальный просмотр production-сборки |
| `npm test` | unit-тесты распознавания жестов и игровой логики (Vitest) |

**Быстрая проверка:** параметр `?stage=3` начинает игру сразу с босса, `?stage=2` — с лазерной засады. Работает и на деплое, и локально.

**Деплой.** При пуше в `main` workflow `.github/workflows/deploy.yml` собирает проект и публикует его на GitHub Pages. Один раз нужно включить в репозитории *Settings → Pages → Source: GitHub Actions*.

Распознавание идёт локально в браузере, видео никуда не отправляется. Модель MediaPipe и WASM-рантайм лежат в самом проекте, CDN не нужен (кроме шрифтов).

## Жесты

| Жест | Действие |
| --- | --- |
| Наклон рук, как у штурвала | корабль летит влево или вправо; скорость зависит от угла |
| Оба кулака | стрельба лазерами |
| Ладони рядом, большими пальцами друг к другу | щит: держит лазеры, плазму и астероиды, тратит энергию |
| Оба указательных пальца вверх | ракета: взрыв по площади, сразу снимает броню босса; заряжается кристаллами |
| Указательный палец в меню | курсор; задержка на кнопке ≈1 с нажимает её |
| Руки убраны из кадра | автоматическая пауза |

## Сценарий

1. **Включить камеру.** Это единственный клик: браузер разрешает звук только после действия пользователя.
2. **Меню.** Курсор следует за указательным пальцем. Мышь тоже работает.
3. **Обучение.** Шесть шагов, по одному жесту. Каждый нужно удержать, полоска показывает прогресс. Ошибки подсвечиваются и объясняются прямо здесь. Обучение запускается автоматически перед первой игрой.
4. **Миссия из трёх этапов.** В каждом главным становится свой жест:

   | Этап | Что происходит | Главный жест |
   | --- | --- | --- |
   | 1. Астероидное поле (30 с) | Астероиды всё быстрее и гуще. Каждый четвёртый летит прицельно на корабль, крупные при попадании раскалываются на два осколка. Кристаллы заряжают ракету. | кулаки, штурвал |
   | 2. Лазерная засада (30 с) | Лучи с предупреждением. Узкий бьёт туда, где сейчас корабль, — уходи в сторону. Двойной оставляет щель — найди её. Луч на весь экран не обойти — нужен щит. | штурвал, щит |
   | 3. Крейсер «Тиран» (босс) | Сначала броня: её сбивают лазеры (15 попаданий) или одна ракета сразу, и она не восстанавливается. Дальше выстрелы бьют по ядру; ракета по ядру снимает 10 HP. Босс стреляет веером плазмы и широкими лучами. На половине здоровья злится: быстрее, больше снарядов, прицельные лучи. | кулаки, ракета, щит |

   Три жизни. Если одна потеряна, сверху время от времени падают **сердца-аптечки**: поймал кораблём — +1 жизнь. Серия сбитых астероидов без урона даёт множитель до ×4, золотые астероиды приносят ×3 очков.
5. **Финал.** Победа над боссом приносит +1000 и +300 за каждую оставшуюся жизнь. Если жизни кончились — поражение. В итогах: счёт, лучший счёт, этап, точность и разбор ошибок в жестах.

## Режим «ошибка» (твист)

Игра распознаёт не только правильные жесты, но и **почти правильные**, и говорит, что именно не так и как исправить.

**Как это работает.** Для каждого из четырёх длинных пальцев по 3D-точкам руки считается состояние: *выпрямлен*, *полусогнут* или *согнут* (`src/gestures/handShape.ts`). Жест — это шаблон состояний пальцев: кулак — все согнуты, ракета — указательный выпрямлен, остальные согнуты. Если рука не совпадает с шаблоном, игра считает «расстояние» до ближайшего жеста. Когда оно маленькое (не хватает одного пальца), это попытка жеста, а не случайное положение руки. Игра называет конкретные пальцы, которые нужно поправить.

Примеры подсказок:

| Ситуация | Что говорит игра |
| --- | --- |
| Кулак сжат не до конца | «Правая рука: не согнут средний палец — сожми кулак полностью, так корабль стреляет» |
| Сжата только одна рука | «Сжата только левая рука — сожми в кулак и правую: стрельба идёт, когда сжаты обе» |
| Для ракеты поднято два пальца | «Левая рука: не прижат средний — для ракеты подними только указательный палец» |
| Поднят палец только на одной руке | «Указательный палец поднят только на правой руке — подними и на левой» |
| Ладони близко, но не вместе | «Ладони почти сомкнуты — сдвинь ладони вплотную, большими пальцами друг к другу» |
| Руки перекрещены | «Левая рука — слева, правая — справа, как на штурвале» |
| Штурвал вывернут | «Наклоняй руки не больше чем на 45° — корабль уже летит на полной скорости» |
| Одна рука пропала из кадра дольше 1,5 с | «Не вижу левую руку — подними её в кадр» |
| Ракета не заряжена / щит разряжен | «Собери ещё 2 кристалла — бирюзовые ромбы», «Подожди, пока полоска энергии восстановится» |
| Летит широкий луч, щита нет | «Луч на весь экран! Его не обойти — поставь ладони рядом, чтобы включить щит» |

Как подсказка показывается:

- Пальцы, которые нужно исправить, **краснеют** на изображении камеры.
- Появляется карточка из двух строк: *что не так* и *как исправить*.
- Подсказка появляется, только если ошибка держится дольше ~0,45 с (для «не вижу руку» — 1,5 с). Кратковременные потери руки моделью сглаживаются: движок держит последнее положение руки 0,3 с. Так мимолётные переходы и сбои распознавания не считаются ошибкой.
- Игра запоминает, исправил ли игрок жест после подсказки: нужное действие сработало в течение 6 секунд. Счётчик «исправлено после подсказки» и топ ошибок показываются в итогах.

## Собственная логика распознавания

Сама модель — готовая (MediaPipe HandLandmarker, 21 точка на руку). Всё остальное написано командой:

- **Классификатор формы кисти.** Состояние пальца вычисляется по 3D-координатам (`worldLandmarks`) через изгиб фаланг и отношение «кончик–запястье / костяшка–запястье». Поэтому он не зависит от поворота руки к камере.
- **Штурвал.** Угол линии между центрами ладоней, с мёртвой зоной 6° и насыщением на 35°.
- **Определение левой/правой руки.** Для двух рук — по положению в кадре: это надёжнее метки модели. Для одной руки — метка модели с поправкой на зеркальность.
- **Фильтр One Euro** сглаживает точки: без дрожания, но почти без задержки.
- **Курсор-палец с dwell-кликом** (наведение с задержкой) для навигации без мыши.
- **Игровая логика** — чистая симуляция без DOM, с детерминированным генератором случайных чисел, поэтому она покрыта тестами.

Тесты (`tests/`): классификация синтетических кистей, конкретные тексты подсказок, штурвал, щит, распределение рук, игровые механики. Пороги дополнительно проверены на реальных фото рук, прогнанных через модель в браузере.

## Бонусы

- **Собственная логика распознавания жестов** (см. выше).
- **Прогресс игрока:** лучший счёт сохраняется между играми, на итогах отмечается новый рекорд и доля исправленных ошибок.
- **Адаптация под телефон:** адаптивная раскладка HUD, фронтальная камера.
- **Звук и эффекты:** синтезированные звуки через WebAudio (выстрелы, взрывы, щит, ракета, предупреждение о лучах), частицы, тряска экрана, подсветка ошибок на пальцах.

## Стек

TypeScript без фреймворка · Vite · MediaPipe Tasks Vision (HandLandmarker, GPU с fallback на CPU) · Canvas 2D · WebAudio · Vitest.

## Структура

```
src/
  core/       камера, обёртка над HandLandmarker, фильтр, геометрия
  gestures/   форма кисти (пальцы, жесты) и управление: штурвал/огонь/щит/ракета + ошибки
  game/       игровая симуляция и отрисовка
  app/        экраны и цикл, обучение, тренер-подсказчик, звук, сохранение лучшего счёта
  ui/         вид камеры со скелетом рук, курсор-палец, иконки
tests/        unit-тесты
public/models модель MediaPipe Hand Landmarker
```
